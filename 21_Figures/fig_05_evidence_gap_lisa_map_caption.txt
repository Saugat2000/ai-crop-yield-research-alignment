Local Moran (LISA) cluster categories for the research-need mismatch, one value per country, 195
countries in the spatial layer. Categories are assigned on Benjamini-Hochberg FDR-adjusted
pseudo p-values at alpha = 0.05 from 9999 permutations under the knn_k6 weights matrix, the
primary matrix for this project; raw unadjusted categories are in the saved data and are never
used to call a cluster. Colour encodes the cluster type, using one palette for every LISA map
this script draws: vermillion High-High, blue Low-Low, orange High-Low, sky blue Low-High, near-
white for a country whose local statistic is not significant after adjustment. Grey hatching
marks a country with no need index, whose mismatch value is unavailable and was mean-filled
before estimation. The mapped variable is the stored evidence_gap column, the country's
research-output percentile minus its research-need percentile, both on a 0-100 scale, so a
positive value marks a country better represented in this literature than its need rank implies.
Global Moran's I for this variable is 0.3868 with pseudo p = 0.0001. Equal Earth projection
(EPSG:8857).
